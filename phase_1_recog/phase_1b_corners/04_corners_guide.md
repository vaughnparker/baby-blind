# 04 - Phase 1B: Corners

## The Corner Buffer

In Old Pochmann corners, the buffer is the **ULB corner** (the corner between the U
face, L face, and B face). In Speffz, this corner has three stickers: **A** (the U
face sticker), **E** (the L face sticker), and **R** (the B face sticker). Because
this is the buffer, you will never memorize A, E, or R — they are excluded from all
corner levels.

The target is **V** (the DFR corner, no setup moves required).

This leaves 21 corner letters to learn: B C D F G H I J K L M N O P Q S T U V W X.

---

## The Corner Levels

You will work through 6 levels. Each level introduces a new set of letters on top of
the previous level. By the end of Level 6, you will be comfortable with all 21 corner
letters.

### Level 1: U V W X
**New letters:** U V W X

**Reasoning:** These are the D face stickers of the D face corners.

```
U: D
V: no setup moves
W: D'
X: D2
```

### Level 2: B C D
**New letters:** B C D

**Reasoning:** These are the U face stickers of the U face corners.

```
B: R2
C: F2 D
D: F2
```

### Level 3: I J Q
**New letters:** I J Q

**Reasoning:** These are the front and back face stickers of the U face corners.

```
I: F R'
J: R'
Q: R D'
```

### Level 4: F M N
**New letters:** F M N

**Reasoning:** These are the left and right face stickers of the U face corners.

```
F: F' D
M: F
N: R' F
```

### Level 5: K L S T
**New letters:** K L S T

**Reasoning:** These are the front and back face stickers of the D face corners.

```
K: F' R'
L: F2 R'
S: D F'
T: R
```

### Level 6: G H O P
**New letters:** G H O P

**Reasoning:** These are the left and right face stickers of the D face corners.

```
G: F'
H: D' R
O: R2 F
P: R F
```

## Full Corner Setup Move Reference

For convenience, here is the complete list of corner setup moves:

```
A: buffer piece (you can't swap with A)
B: R2
C: F2 D
D: F2
E: buffer piece (you can't swap with E)
F: F' D
G: F'
H: D' R
I: F R'
J: R'
K: F' R'
L: F2 R'
M: F
N: R' F
O: R2 F
P: R F
Q: R D'
R: buffer piece (you can't swap with R)
S: D F'
T: R
U: D
V: no setup moves
W: D'
X: D2
```
